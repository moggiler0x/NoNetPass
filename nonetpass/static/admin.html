Настроить роутер автоматически

NoNetPass сам зайдёт в роутер, поставит Captive portal, закрепит IP этого компьютера, настроит гостевую сеть ClientPulse и подключится к роутеру. Пароль администратора сохраняется в файл настроек этого компьютера, только если роутер не дал создать отдельного пользователя для NoNetPass.

Или скачать конфиг и загрузить вручную

Без startup-config в архиве будут команды CLI вместо готового файла: файл целиком заменяет настройки роутера, поэтому собирается только из его собственного конфига.
