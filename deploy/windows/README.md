# NoNetPass на Windows-компьютере

Для роутеров, на которых NoNetPass сам работать не может (Keenetic Air, Lite,
Start и другие модели без USB): NoNetPass ставится на любой Windows-компьютер
в той же сети и открывает окна через RCI роутера.

## Установка

1. Скачайте [`install.cmd`](install.cmd) и запустите двойным щелчком. Он
   попросит права администратора и сам скачает `install.ps1`, если его нет
   рядом.
2. Установщик ставит Python 3.12 (если его нет), NoNetPass из GitHub в
   `C:\ProgramData\NoNetPass`, добавляет задачу «NoNetPass» в планировщик
   (запуск при включении компьютера, перезапуск при падении), открывает порт
   8080 в брандмауэре и отключает сон при питании от сети.
3. В конце откроется админ-панель на вкладке «Keenetic» и будет показан PIN.

Повторный запуск `install.cmd` обновляет NoNetPass, настройки и PIN остаются.

## Подключение к Keenetic

На вкладке «Keenetic» в админ-панели:

1. Введите RADIUS NAS ID от ClientPulse. Режим «На отдельной машине» и IP этого
   компьютера уже подставлены.
2. Приложите startup-config роутера («Управление» → «Параметры системы» →
   «Файлы») и нажмите «Скачать конфиг». С галкой «Сразу подключить» NoNetPass
   запишет логин и пароль роутера в свой `nonetpass.env` и перезапустится.
3. Загрузите `startup-config.txt` из архива обратно на роутер.

Что генератор добавляет в конфиг для этого режима: пользователя `nonetpass`
с доступом к RCI и список доступа `_NONETPASS_PORTAL`, который пускает гостей
из гостевой сети к порталу на этом компьютере (по умолчанию гостевая сеть в
домашнюю не ходит).

Закрепите за компьютером постоянный IP в роутере («Список устройств» →
компьютер → «Постоянный IP-адрес»), иначе после смены адреса портал станет
недоступен.

## Файлы

`C:\ProgramData\NoNetPass\`:

* `nonetpass.env` — настройки (PIN, роутер, Telegram-бот); после правки
  перезапустите задачу «NoNetPass» или компьютер;
* `nonetpass.log` — журнал службы;
* `nonetpass-sessions.jsonl`, `nonetpass-state.json` — журнал сессий и состояние;
* `run.cmd` — запуск в цикле, его вызывает планировщик.

Удаление: `Unregister-ScheduledTask NoNetPass`, удалить правило брандмауэра
«NoNetPass» и папку `C:\ProgramData\NoNetPass`.
